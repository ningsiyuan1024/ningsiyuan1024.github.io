四个工具，一个编码 Agent。

Pi 由 Mario Zechner 开发，是近期爆火的 OpenClaw 项目的底层引擎。与主流 Agent 不断堆叠功能不同，Pi 的核心是极致的精简，它的系统提示词最短，并且只有四个核心工具：

• Read：读取文件
• Write：写入文件
• Edit：编辑文件
• Bash：执行命令让 Agent 自己扩展自己

Pi 的设计哲学是“代码编写代码”，它没有 MCP 支持，不鼓励用户下载插件，而是让用户告诉 Agent 需要什么能力，由 Agent 自己编写代码来实现。这种“自主进化”的理念，与依赖“社区生态”的 MCP 形成了鲜明对比。


为了支撑这一理念，Pi 在架构上有几个关键设计：

• 热重载：扩展代码编写后可立即重载和测试，无需重启会话，提升了迭代效率。

• 状态持久化：在会话文件中维护自定义消息，使得扩展可以维护自身状态。

• 会话树：最具特色的架构设计。用户可以在任意节点创建分支来完成临时任务（如修复 bug），完成后回到主会话，且主会话的上下文不受影响，实现了上下文隔离。

• 模型无关性：会话可以在不同模型提供商之间移植。


Agent 造工具，人只管提需求

开发者Armin 强调，他使用的扩展没有一个是他自己写的，全是 Agent 按照他的规格创建的。具体实践包括：

• 用基于 CDP 的 skill 替代浏览器自动化 MCP。

• 让 Agent 生成符合他个人偏好的 commit 工具和更新 changelog。

• 拦截 pip 调用并重定向到 uv。

在这种模式下，工具不再是开发者的固定资产，而是按需生产的“消耗品”，开发者的成本从“寻找、评估、维护”变成了“描述需求、等待交付”。
