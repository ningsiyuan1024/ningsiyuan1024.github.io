Channel（渠道端）
对接各类IM平台（钉钉、飞书等），接收外部消息并转换为内部统一格式，同时也负责把智能体的回复发送回IM。

Gateway（网关）
核心控制平面，负责接收消息、路由分发、回复投递，协调各模块之间的通信。

Agent Runtime（智能体运行时）
智能体运行引擎，包含以下模块：
Agent Loop：智能体主循环，负责循环推理：“收到指令→思考步骤→调用工具→再思考”
Memory：记忆系统，管理对话历史和上下文
Tool：工具调用接口，让智能体能使用外部功能，如文件操作、浏览器控制等
Skill：智能体执行任务或者使用工具的指引，通过模块化插件的方式灵活定义功能

Node（设备端）
运行在用户设备（iOS、Android、macOS）上的伴侣程序，通过Gateway远程控制设备能力（如摄像头、屏幕截图等）。

工作流程

1. Channel接收消息并标准化
2. Gateway 根据会话状态调度合适的Agent
3. Agent Runtime进行推理，可能需要调用工具或技能
4. 设备操作，Gateway通过Node远程执行
5. 最终回复经Channel返回给用户
