# 16:9 行业风格品牌信息图

为【品牌名称】制作一张 **16:9 行业风格品牌信息图**，展示完整的【流程类型】旅程，并以【品牌调性】进行叙事表达。

**顶部标题区**：居中标题“【英文标题】”，使用【字体风格】字体，颜色为【品牌色】；可选副标题“【中文标题】”；右上角放置【品牌名称】Logo（【Logo描述】）。

**背景**：采用从【颜色1】到【颜色2】的无缝渐变，营造【氛围描述】。

**中央 Knolling 陈列区（画面中心 40%）**：采用博物馆级平铺静物构图。中央放置主视觉产品【主产品描述】，以完美【横向/纵向】方式陈列；周围产品按严格 90 度几何关系、等距排列：上方【产品2】、左侧【产品3】、右侧【产品4】、下方【产品5】。Knolling 区域背景与整体背景保持相同【色彩方案】，无缝融合。使用单一顶置柔光箱照明，所有阴影统一落向右下方，并突出【纹理/细节说明】。

**8 个电影感流程画面**：按顺时针环绕中央陈列区排布，并且每个画面都必须带有清晰可见的编号标签。  

- **① 左上（10:30）**：画面内容【步骤1场景描述——强调手工技艺特写、人手操作细节、触觉瞬间】；标签：**①【步骤1标题】**  

- **② 上中（12:00）**：画面内容【步骤2场景描述——微距/特写手法、工匠双手、工具使用细节】；标签：**②【步骤2标题】**  

- **③ 右上（1:30）**：画面内容【步骤3场景描述——手部动作、材料质感、精准操作】；标签：**③【步骤3标题】**  

- **④ 右侧（3:00）**：画面内容【步骤4场景描述——工艺细节、手指位置、力度控制】；标签：**④【步骤4标题】**  

- **⑤ 右下（4:30）**：画面内容【步骤5场景描述——传统技法、世代传承、手势智慧】；标签：**⑤【步骤5标题】**  

- **⑥ 下中（6:00）**：画面内容【步骤6场景描述——关键时刻、精密调整、匠心瞬间】；标签：**⑥【步骤6标题】**  

- **⑦ 左下（7:30）**：画面内容【步骤7场景描述——品质把控、检验手法、专业判断】；标签：**⑦【步骤7标题】**  

- **⑧ 左侧（9:00）**：画面内容【步骤8场景描述——最终呈现、完美收尾、成品时刻】；标签：**⑧【步骤8标题】**

**连接设计元素**：使用优雅纤细的弧形线条（2px 宽），颜色为【品牌色】，按顺时针顺序平滑连接：**① → ② → ③ → ④ → ⑤ → ⑥ → ⑦ → ⑧**。每个连接点设置小型圆形徽章，边框颜色为【颜色】，内部以【字体风格】显示对应编号。从第 ⑧ 个画面延伸出一条优雅的渐变消隐箭头，柔和弯向中央【产品】：起始颜色为【颜色】，透明度从 100% 逐渐减弱至 10%，像【隐喻描述】一样自然过渡到中央产品。

**手工工艺强调**：每一个流程画面中都必须将“人手 / 工艺动作”作为主要或次要主体，展示双手、手指、正在使用的工具、正被处理的材料；捕捉触摸、按压、感受、调整、检查等触觉瞬间；强调手指位置、握持力度、细微调节；展现材料纹理、专注状态、专业经验与劳动痕迹；突出代际传承的技艺智慧。

**编号技术规范**：每个编号（①②③④⑤⑥⑦⑧）都必须以高对比、独立清晰的方式呈现；编号必须置于圆形徽章中，并带有清晰边框；编号最小字号 **24pt**，文字标签最小字号 **16pt**；位置为每个画面正下方居中；中文品牌使用传统中文圈号（①②③④⑤⑥⑦⑧）；确保编号不被图像或其他设计元素遮挡。编号徽章配色：边框【徽章颜色】、数字【数字颜色】、背景【背景颜色】。

**色彩和谐**：整体背景为统一渐变【颜色1】到【颜色2】；Knolling 区域使用完全一致的渐变背景，无缝衔接；产品颜色为【产品色盘】；连接元素颜色为【箭头颜色】；编号徽章为【徽章风格描述】；文字排版颜色为【文字色彩方案】。

**整体美学**：【品牌个性描述】。整体设计应呈现【参考美学】风格——【关键形容词】，歌颂【品牌价值】；并体现【工艺哲学描述】。

**技术规格（摄影规格）**：分辨率 **8K**，保证高端品质；摄影风格为【微距 / 纪实 / 产品】摄影，结合【灯光风格】；景深为 **f/【光圈值】**，实现【焦点效果】；灯光为【灯光描述】；调色为【调色说明】；材质细节强化【材质类型】纹理，并使用正确的 PBR 材质表现；特殊效果为【氛围特效】（如蒸汽、颗粒等）。
