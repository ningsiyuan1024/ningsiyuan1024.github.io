腾讯开源RAG应用 WeKnora 核心功能

核心特性

• Agentic RAG：不同于传统 RAG，它会进行多轮推理，动态决定是否检索知识库、调用外部工具（如网络搜索），甚至进行自我反思，从而生成更精准的回答。

• 混合检索：为了提升召回率，它结合了关键词、语义向量和知识图谱等多种检索方式。

• 本地私有化部署：项目采用 MIT 协议，支持完整的本地部署，保证了数据安全。

• 高度可配置：从模型参数、分块策略到检索阈值，都可以在界面上自由配置，让整个过程更透明可控。

使用流程

1. 通过 Web UI 创建知识库，并上传文档、图片或导入网页链接。

2. 系统会自动处理内容，进行解析、分块和向量化。

3. 配置模型和 MCP 服务器，接入本地或外部大模型。

4. 在对话界面提问，系统会通过多轮推理生
