阿拉丁神灯其实是最早的自然语言操作系统。

用户不需要学习任何 UI，只要用自然语言描述 intent，灯神就会自动完成 task planning、resource allocation、tool execution，最后直接把结果作用到现实世界。

这已经不是聊天机器人了，是一个拥有 action permission 的 Agent。

阿拉丁说“我要变成王子”，灯神不会给他生成一篇《如何成为王子》，而是直接调用现实世界 API：生成身份、服装、财富、随从和社会地位，把一个模糊目标拆成几十个子任务并执行。

这其实就是现在大家想做的 Agentic OS：用户只负责说“我要什么”，系统负责决定“怎么做”。

神灯甚至几乎没有 interface。摩擦神灯相当于 authentication，开口就是 prompt。人类从 command line 做到 GUI，最后发现终极交互方式可能还是直接说人话。

但问题也很明显：灯神拥有修改现实世界状态的 root access，却没有成熟的 permission layer。自然语言里的“让我有钱”“让我成为王子”也不是完整 specification，系统必须自己补全大量隐含条件。

Agent 越强，理解错 intent 的代价反而越大。

以及最致命的一点：Disney 版每个用户只有三次 API call 💔
