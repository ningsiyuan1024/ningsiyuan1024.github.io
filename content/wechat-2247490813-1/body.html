如果你还在好奇什么是JEV

1. fast-jev-compaction
Claude Code 插件。每次工具调用后，用 Jev 判断哪些内容该保留、压缩或丢弃，减少上下文膨胀。
github.com/tamaratran/fas…

2. jev-browser
让 LLM 负责规划，Jev 负责浏览器里的具体选择。支持 CLI、Library 和 MCP。
github.com/Ying-Kai-Liao/…

3. jev-search
把 Jev 用在搜索流程里，负责理解查询、选择信息源、筛选结果。
github.com/superagents-la…

4. Reticle
给 Web 和桌面应用增加运行时感知能力，帮助 Agent 理解自己正在操作的界面。
github.com/reticlehq/reti…

5. NanoJev
一个 Jev 的轻量复现项目，包含并行决策、动态候选项和完整训练流程。
github.com/TianyuCodings/…

6. open-alternative-jev
尝试用开源模型复现 Jev 风格的 System One 决策层，并提供基准测试。
github.com/ikermoel/open-…

7. pi-jev
把 Jev 接入 Pi coding agent，用来控制工具调用，也支持类型化、带置信度的回答。
github.com/y0usaf/pi-jev

8. hermes-jev-skills
直接把 Jev 接进 Hermes、Claude Code 和 Codex，覆盖模型路由、记忆、上下文压缩、Skill 选择和浏览器操作。
github.com/kerpopule/herm…
