Pi 能在脚本里批量调用 bash、read 这些
编码工具；

OpenCode 的 code mode 主要用来组合大量 MCP 和外部 API，编码工具还是直接调。

取舍不同：
OpenCode 的作者 Dax 在 X 上说过(x.com/thdxr/status/2…)，他们特意不用 QuickJS，是嫌 WASM、worker 和跨线程传值太麻烦。
而 Pi 选的正是QuickJS，换来的是真正的隔离和内存上限。
