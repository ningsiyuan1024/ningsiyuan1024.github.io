2. hermes-agent（NousResearch）
github.com/NousResearch/h…
⭐7.6k｜本周 +5.1k

会自己进化的 Agent。

核心设计只有一句话：完成复杂任务之后，把这次的经验自动写成一个新 Skill；下次遇到类似任务，调用这个 Skill，并在使用中继续改进它。

越跑越聪明，Skill 越积越多。

$5 VPS 可以跑。Telegram / Discord / WhatsApp / Signal / CLI 全平台支持。模型随时换，OpenRouter / Kimi / MiniMax / OpenAI 都行，一行命令切换，不改代码。

3. BitNet（微软）
github.com/microsoft/BitN…
⭐34.7k｜本周 +6k

1-bit LLM 的官方推理框架。

量化到 1-bit 之后发生了什么：

• ARM CPU 加速 1.4–5x
• x86 CPU 加速 2.4–6.2x
• 能耗降低 55–82%
• 100B 参数的模型，单颗 CPU 可以跑

不需要 GPU。你现在用的 VPS 就够了。

本地跑大模型这件事，正在从"有 GPU 的人的游戏"变成人人可玩。
