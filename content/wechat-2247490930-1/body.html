OpenCode 2.0 做了重大架构升级，让系统更灵活、可扩展，并更好地支持 Agent的复杂工作流。


架构变化：


客户端/服务器模型成为默认：以前可选的 client/server 架构现在是标准模式。系统会自动在本地运行一个中心化的 ground process，所有界面（TUI、Web、桌面应用）以及编程客户端都会自动发现并连接到它。

全新 API：从零重写，基于真实使用场景设计，支持几乎所有代理可能需要的操作，并且能够自我感知，例如可以调用自己的 API 自动把会话移到 Git worktree 中。

热重载：插件和组件支持热重载，Agent可在会话中途编写并加载新插件。


新功能：

Code Mode（@opencode/codemode）：引入轻量级 JavaScript 解释器。可以把 MCP 服务器或 OpenAPI 端点转成可调用的函数，让代理直接编写并运行脚本（无需 Node.js VM 或 QuickJS）。默认支持将多个工具组合在一轮调用中完成，减少上下文占用。

后台任务与编排：Ground Sub-agents：主代理可以自动或手动启动子代理（甚至用不同模型），例如一边写代码一边让子代理做代码审查。

后台 Shell 命令：长时间运行的命令可以异步执行，不阻塞主代理，支持快捷键（如 Ctrl+B）移到后台，完成后有通知。 插件系统全面升级：内部超过 80 个功能以插件形式实现，TUI 插件从实验性变为稳定（基于 OpenTUI），并支持热重载。


注：OpenCode 1.0 的插件不兼容 2.0。 服务器 API 完全重新设计，旧 API 不再支持。 tui.json 配置格式有调整。


官方提供了迁移指引：http://opencode.ai/v2/docs/migrate-v1/…，可以让 OpenCode 协助完成迁移。
