Cowork 到底是什么

Cowork 是内置在 Claude Desktop（桌面端） 里的 智能体（agentic）桌面工具。

它让 Claude：

  • 直接读写你电脑上指定的文件夹
  • 自主执行多步骤任务
  • 在复杂任务里可以并行派生子智能体来分工完成

关键点：不需要终端、不需要命令行、不需要写代码。

你只需要描述“完成的标准（done looks like）”。Claude 会：

1. 制定计划
2. 把任务拆成子任务
3. 在你机器上的沙盒 VM 里执行
4. 把最终成品文件交付到你的目录

Cowork 不是聊天。它是任务委托。你可以离开，回来时工作已经交付完成。

Cowork 与 Chat / Claude Code 的区别

Claude Chat（聊天）

  • 提示 → 回复
  • 你一直在回路里（in the loop）
  • 适合：头脑风暴、写草稿、回答问题

Claude Code（代码）

  • 面向开发者
  • 在终端里运行：写代码、执行命令、管理 git 仓库
  • 很强，但不适合不写代码的人

Claude Cowork（同事）

  • 非技术操作者的中间地带
  • 有 Claude Code 的自主执行力
  • 但通过可视化文件夹/文件工作，而不是终端命令
  • 适合：业务 owner、运营、市场、销售等“要交付成果的人”

用一句话记住它们：

  • Chat = 回答问题的助理
  • Code = 构建软件的开发者
  • Cowork = 负责把任务做完的员工

对大多数生意人来说，Cowork 才是“改变游戏规则”的那个。

15 分钟搭建（照做就能用）

Step 1：获取访问权限

  • 从 claude.com/download 下载 Claude Desktop
  • 使用付费计划登录（Pro 版 $20/月通常足够）
  • 打开应用，点击顶部 “Cowork” 标签

Step 2：创建专用工作区（不要给全盘权限）

创建一个专用文件夹给 Cowork，不要把整个 Documents 都共享出去。

推荐结构：

~/Claude-Workspace/
├── context/      # 你的长期上下文文件
├── projects/     # 活跃项目文件夹
└── outputs/      # Claude 交付成品的目录

这么做可以控制“爆炸半径”：Cowork 对你共享的目录拥有真实读写权限。

Step 3：创建 3 个上下文文件（最高杠杆）

在 context/ 里创建以下三个文件：

1) about-me.md

  • 你是谁、你做什么、你当下的优先级
  • 不是简历，而是你每天真实在推进的工作

2) brand-voice.md

  • 你的表达风格：语气、常用句式、你喜欢/讨厌的措辞
  • 贴 2–3 段你真实写过的内容作为样例

3) working-preferences.md

  • 你希望 Claude 怎么工作
  • 例：开始前先提问、先给计划、未确认不删除文件等

这三个文件能极大减少“AI 输出很泛”的问题：

没有它们，每次会话都从零开始；有了它们，Claude 一上来就知道你的标准和口吻。

Step 4：设置全局指令（每次自动生效）

路径：Settings → Cowork → Edit Global Instructions

粘贴类似下面的内容（按需改名/角色）：

I'm [Name], [Role]. Before starting any task, read my context files first.
Always ask clarifying questions before executing. Show a brief plan before taking action.
Default output: .docx. Never delete files without my explicit approval.

这些会应用到每个 Cowork 任务里；你每次只需要写“这次要做什么”。

建议先装哪些插件（从“好玩”到“替代半个软件栈”）

插件把 Skills、斜杠命令、连接器打包成角色化能力。

想让 Cowork 真正变成生产力引擎，插件是关键。

先装这几个：

1）Productivity（人人必装）

  • 管理任务、日程、日常工作流
  • 输入 /productivity:start，Claude 会帮你复盘当天安排
  • 可连接 Slack、Notion、Asana、Linear 等

2）Data Analysis（如果你常碰表格/数据）

  • 丢一个 CSV，输入 /data:explore
  • 自动总结字段、标异常、建议分析方向
  • 可把自然语言转换成 SQL 查询

3）再选一个“岗位专用插件”

  • 销售：/sales:call-prep、/sales:battlecard
  • 市场：/marketing:draft-content
  • 财务：报表、差异分析
  • 法务：合同审阅、NDA 分拣

安装路径：左侧栏 Customize → Browse plugins → Install

建议先装 2 个，熟了再加。

3 个你今天就能跑的用例

用例 1：整理一个乱七八糟的文件夹

场景：6 个月文件都堆在一个目录里：收据、合同、笔记、截图……

提示词：

Organize all files in this folder into subfolders by type (receipts, contracts, notes, images).
Use the format YYYY-MM-DD-descriptive-name for all filenames.
Create a summary log documenting every change.
Don't delete anything.
If a file could belong to multiple categories, put it in /needs-review.

结果：Claude 读完所有文件 → 分类 → 重命名 → 建目录 → 输出变更日志。

10 分钟搞定原本 2 小时的活。

用例 2：每周研究简报（周一早上自动交付）

场景：每周一想要竞品更新、行业新闻、价格变化等摘要。

提示词（配合 /schedule）：

Every Monday at 7am, research [competitor names] for news, product updates, or pricing changes.
Check [industry publication] for relevant articles.
Save a summary to /weekly-briefings/YYYY-MM-DD-brief.md.
Only include items from the past 7 days.

结果：只要电脑开着且 Claude Desktop 在运行，周一早上醒来就有简报文件。

用例 3：把原始笔记变成客户可交付报告

场景：你有会议记录、语音转写、研究链接，但需要一份排版规范的客户报告。

提示词：

Using the files in /client-a/raw-materials, create a client-ready report.
Include: executive summary, key findings, recommendations, and next steps.
Match the format of the template in /templates/client-report-template.docx.
Save to /client-a/deliverables.

结果：Claude 读取所有原材料 → 综合 → 按模板格式产出 → 保存到交付目录。

把 90 分钟的工作压到 15 分钟。

心智转变：Cowork 奖励“系统工程”，不是“提示词工程”

Cowork 用得不顺的人，往往在每个任务上都写超长提示词，导致结果不稳定。

用得最顺的人，花一个下午把这些搭好：

  • 上下文架构（context files）
  • 全局指令（global instructions）
  • 文件夹结构（workspace layout）

然后日常只需要写 10 个字的任务描述，就能稳定交付“可直接发给客户”的成品。

ChatGPT 时代奖励巧妙提示词。Cowork 时代奖励高质量配置。

前置投入 2 小时，之后每天都能回本。
