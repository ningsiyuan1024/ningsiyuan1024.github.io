Cowork 实际上是什么

Cowork 是一个内置在 Claude Desktop 应用里的「代理式（agentic）桌面工具」。它让 Claude 对你电脑上的文件夹拥有直接的读/写权限，能够自主执行多步骤任务，并具备协调并行子代理（sub-agents）的能力——全程不需要终端或命令行。

它于 2026 年 1 月 12 日上线。可用范围随后逐步扩大：1 月 16 日开放给 Pro 订阅用户，1 月 23 日开放给 Team 与 Enterprise，2 月 10 日支持 Windows（x64）。2 月 24 日，Anthropic 发布了一次重大企业更新，带来新的插件（plugins）、连接器（connectors）和管理控制（admin controls）。

与普通 Claude Chat 的关键区别：Chat 是「提示词—回复」。Cowork 是「任务委派」。你描述一个目标结果，Claude 会制定计划、拆分子任务、在你机器上的沙盒 VM 中执行，并把完成的文件交付到你的文件夹。你可以离开，回来时拿到已完成的成果。

Cowork 构建在与 Claude Code（Anthropic 的终端式编码工具）相同的代理架构之上。据称 Boris Cherny 使用 Claude Code 本身在大约 10 天内构建了 Cowork。

目前仍是研究预览。Anthropic 明确表示：代理安全仍在积极开发中。请据此谨慎使用。

Requirements（要求）

  • Platform（平台）：macOS（universal）或 Windows（仅 x64）。不支持 Windows arm64。不支持移动端。不支持 Web。
  • Subscription（订阅）：任意付费计划：Pro（$20/月）、Max 5x（$100/月）、Max 20x（$200/月）、Team（$25+/席位/月）、Enterprise（定制）
  • Desktop App（桌面应用）：从 claude.com/download 下载最新版本
  • Internet（网络）：会话期间需要全程保持联网
  • App must stay open（应用必须保持打开）：关闭桌面应用会终止会话。睡眠可以，但退出应用不行。

Step 1：安装并进入 Cowork

1. 从 claude.com/download 下载 Claude Desktop 应用。
2. 使用你的付费账号登录。
3. 打开应用。在顶部找到模式选择器，点击 “Cowork” 标签，从 Chat 切换到 Tasks 模式。
4. 你已进入 Cowork。

Step 2：设置工作文件夹（Working Folder）

Cowork 采用文件夹权限模型：你授予 Claude 访问某个目录的权限，它就能在其中读取、编辑并创建文件。

专用工作区方法（The dedicated workspace approach）

建议为 Cowork 创建一个专用文件夹，而不是把整个 Home 目录或 Documents 目录都授权给它。这是 Anthropic 自己的安全文档确认的最佳实践。

~/Claude-Workspace/
├── context/          # 你的长期上下文文件
├── projects/         # 进行中的项目文件夹
│   ├── client-a/
│   └── client-b/
└── outputs/          # Claude 交付成品的位置

为什么重要：Cowork 虽然运行在 VM 中，但对你共享的任何文件夹都拥有真实的读/写/删除权限。Anthropic 的安全指南明确警告：

“如果被指示，Claude 可能采取潜在破坏性行为（例如删除本地文件）。”

专用工作区能限制爆炸半径。

先备份（Backup first）

在第一次执行真实任务前，把你计划共享的文件夹内容备份一份：

cp -R ~/Claude-Workspace/ ~/Claude-Workspace-Backup/

这是很便宜的保险。

用云同步实现跨设备访问（Cloud sync for cross-device access）

Cowork 是纯桌面端工具，没有内置同步。如果你需要多设备工作，把工作区放到云同步目录（iCloud Drive、Dropbox、OneDrive）里，至少能保持文件一致。注意：这不会同步 Cowork 会话，只同步文件。

Step 3：写你的上下文文件（Context Files）

这是最具杠杆的设置步骤。Cowork 输出质量与您在文件里提供的上下文质量几乎成正比。

在 context/ 文件夹中创建以下 .md（Markdown）文件。Markdown 是 Claude 最省 token 的读取格式。

about-me.md

# About Me

## Role & Responsibilities
- [你的名字、职位、公司]
- [你日常做什么]
- [你协作的关键干系人]
- [在你的角色里，什么叫成功]

## Domain Context
- [行业/领域特定背景]
- [你使用的关键术语或框架]
- [你工作流中的工具与平台]

## Example Work
[粘贴 1-2 个你满意的输出样例——报告、邮件、分析等。
这能给 Claude 一个关于质量与风格的具体参照。]

brand-voice.md

# Communication Style

## Tone
- [例如：直接、简洁、无废话；必要时技术性表达]
- [你常用的表达]
- [你觉得别扭/不像你的表达]

## Writing Samples
[粘贴 2-3 段你真实写过的短文本——邮件、帖子、文档片段。
这些比抽象描述更有用。]

## Anti-patterns
- [例如：不要把 “leverage” 当动词使用]
- [例如：不要用 “I hope this email finds you well” 开头]

working-preferences.md

# How I Want Claude to Work

## Process
- 在开始任何非简单任务前先问澄清问题
- 执行前先把计划给我看
- 把输出保存为 [.docx / .xlsx / .md ——按你的偏好]

## Output Style
- [偏短还是偏详细]
- [偏好的排版/格式习惯]
- [文件命名规范]

## Guardrails
- 未经我明确确认，绝不删除文件
- 不要修改指定输出文件夹以外的任何文件
- 行动前明确标注假设

复利效应（The compounding effect）：这些文件会越用越好。每次 Claude 的输出不理想，就更新对应的上下文文件。你也可以让 Claude Desktop 根据你们过往讨论帮你写好这三个文件。

Step 4：设置全局与文件夹指令（Global & Folder Instructions）

指令（Instructions）是会在每次 Cowork 会话开始时自动加载的常驻规则。

Global Instructions（全局指令）

1. 在 Claude Desktop 中打开 Settings > Cowork。
2. 点击 Global Instructions 旁的 Edit。
3. 写入你的核心偏好并保存。

这里建议写什么（从上下文文件中提炼）：

I'm [Name], [Role] at [Company]. I work on [domain].

Communication: Direct, concise, no filler. Default to .md for drafts, .docx for final deliverables.

Process: Always ask clarifying questions before starting complex tasks. Show your plan. Explain assumptions.

Safety: Never delete files without my explicit approval. Flag any destructive actions before executing.

保持简短。全局指令每次都会加载，会占用上下文窗口。

Folder Instructions（文件夹指令）

文件夹指令在你选择该文件夹时生效，用于项目或客户的专属信息。

示例：你的 projects/client-a/ 文件夹可以写：

Client A is a Series B fintech company. Brand voice: professional but approachable.
Key contacts: [names]. Current priorities: [list]. 
Use their terminology: "members" not "users", "platform" not "app".

Claude 也可以在会话过程中根据学到的信息帮你更新 folder instructions。

Step 5：安装插件（Install Plugins）

插件把技能、斜杠命令、连接器和子代理打包成面向角色的工具包。

安装方法（How to install）

1. 在 Cowork 中点击左侧栏的 Customise。
2. 点击 Browse plugins 查看可用插件。
3. 对想要的插件点击 Install。
4. 或在 claude.com/plugins 浏览。

当前有哪些（截至 2026 年 2 月 27 日）

Anthropic 在 1 月 30 日开源了 11 个插件，并在 2 月 24 日发布了更多插件。开源仓库：github.com/anthropics/knowledge-work-plugins

  • 核心插件（1 月 30 日发布）：Productivity、Marketing、Sales、Finance、Data Analysis、Legal、Product Management、Customer Support、Enterprise Search、Biology Research、Plugin Management（用于构建自定义插件）。
  • 2 月 24 日新增：HR、Engineering、Design、Operations、Financial Analysis、Investment Banking、Equity Research、Private Equity、Wealth Management。另有 Tribe AI 合作方提供的 Brand Voice 插件。

每个插件本质是一个文件夹，包含：

  • .claude-plugin/plugin.json — Manifest
  • .mcp.json — Tool connections
  • commands/ — 你显式触发的斜杠命令（例如 /sales:call-prep）
  • skills/ — Claude 自动调用的领域知识

插件本质上就是 Markdown 文件。你可以定制任意插件，或零代码构建自己的插件。

先装哪些（Which to install first）

建议从 Productivity（通用）开始，再装一个与你岗位最匹配的角色插件。在任意 Cowork 对话里输入 / 可查看已安装插件的斜杠命令。

定制插件（Customising plugins）

安装后点击插件的 Customise，与 Claude 一起调整技能、命令、连接器以适配你的工作流。默认插件只是起点，真正价值来自加入你公司专属的上下文、术语与流程。

Step 6：连接你的工具（Connect Your Tools）

连接器（Connectors）通过 MCP（Model Context Protocol）把 Claude 接入外部服务。连接完成后，Claude 可在 Cowork 会话中拉取这些工具的实时数据。

连接方法（How to connect）

1. 打开 Claude Desktop 的 Settings > Connectors（或访问 claude.ai/settings/connectors）。
2. 浏览可用集成。
3. 选择连接器并完成授权。

可用连接器（截至 2026 年 2 月 24 日）

根据 Anthropic 公告确认：Google Drive、Gmail、Google Calendar、Slack、Notion、Asana、Linear、Jira、Monday、ClickUp、Figma、Amplitude、Pendo、Intercom、HubSpot、Close、Clay、ZoomInfo、Fireflies、Microsoft 365、Snowflake、Databricks、BigQuery、Hex、Box、Egnyte、DocuSign、FactSet、MSCI、Harvey、Apollo、Outreach、SimilarWeb、LegalZoom、WordPress、Canva、Ahrefs、Klaviyo、Guru、Benchling 等，以及其他更多。

第一个该连什么（First connector to set up）

连接你最常用的工具即可。对大多数知识工作者来说，Slack、Google Drive 或 Notion 通常是最高杠杆起点。

Step 7：运行你的第一个任务（Run Your First Task）

验证提示词（Verification prompt）

新建 Cowork 会话并选中工作区文件夹，输入：

Read all the files in the context folder. Then tell me:
1. What you know about me
2. How I prefer to work  
3. What standing preferences you're aware of

Do not start any other work yet.

如果输出能准确反映你的上下文文件与全局指令，说明配置正常；如果不对，现在就修正。

第一个真实任务（First real task）

选一个你非常熟悉、能快速判断对错的任务：

I want to [DO X] so that [Y IS BETTER].

First, read all relevant files in this folder.
Before you start executing, ask me clarifying questions so we can align on approach.
Only begin work once we've agreed on the plan.

观察它如何执行：回答它的问题、迭代你的指令。早期最合适的任务包括：

  • 按类型与日期整理混乱文件夹
  • 把零散笔记生成格式化报告
  • 从收据图片生成电子表格
  • 基于文件夹里的模板起草文档

定时任务（Scheduled tasks）

Cowork 现已支持循环任务。在任意 Cowork 任务中输入 /schedule，或点击左侧栏的 Scheduled。注意：任务只会在电脑保持唤醒且应用打开时运行。

安全：你必须知道的事（Safety: What You Need to Know）

这一节比任何效率技巧都重要。Cowork 对你的文件有真实权限。Anthropic 的安全文档对风险讲得很明确。

已验证的安全特性（Verified safety features）

  • 删除保护（Deletion protection）：Claude 在永久删除文件前需要你显式授权；你会看到提示并必须点击 Allow。
  • VM 隔离（VM isolation）：Cowork 在沙盒虚拟机中运行（macOS 使用 Apple Virtualization Framework）。代码在隔离环境执行，但 Claude 仍能对你共享的文件夹做真实修改。
  • 对抗提示词注入的训练（Model training against prompt injection）：Anthropic 用强化学习训练 Claude 拒绝恶意指令，并用内容分类器标记潜在注入。

需要管理的真实风险（Real risks to manage）

1. 提示词注入（Prompt injection）：如果 Claude 读取了恶意文档或网站，隐藏指令可能改变其行为。尽量限制 Claude 在 Chrome 中只访问可信站点；Web 内容是主要注入入口。
2. 文件破坏（File destruction）：Claude 能修改或删除你共享文件夹中的内容。使用专用工作区、保持备份，并在全局指令里加入“未经明确确认不得删除”。
3. 范围蔓延（Scope creep）：关注异常模式——Claude 访问你没提到的文件，或任务范围超出你要求。感觉不对立刻停止任务。
4. 无审计日志（No audit logging）：Cowork 活动不会出现在审计日志、Compliance API 或数据导出中。不要把 Cowork 用于受监管的工作负载。
5. 会话依赖应用保持打开（Session persistence）：应用必须一直开着；关闭会中断任务且无法恢复。

建议设置的安全默认项（Safety defaults to set）

把下面这些加入全局指令：

- Never delete any files without my explicit confirmation
- Never modify files outside the designated output folder
- Show me your plan before executing any multi-step task
- If you're unsure about any instruction, ask rather than assume

跨应用工作流（Cross-App Workflows）

Cowork 现在可以在 Excel 与 PowerPoint 插件之间传递上下文。Claude 能在 Excel 中分析数据，并把图表直接移入演示文稿，不需要你手动切换应用。

  • Requirements（要求）：Mac 用户需为 Max、Team 或 Enterprise 计划；必须安装 Claude in Excel 与 Claude in PowerPoint 插件；Windows 暂不支持此功能。
  • Caution（注意）：数据可能在应用间流动。Cowork 运行时避免在这些插件中处理敏感信息。
